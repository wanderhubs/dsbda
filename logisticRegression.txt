import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix

df = pd.read_csv("Social_Network_Ads.csv")

print(df.head())
print(df.info())

X = df[['Age', 'EstimatedSalary']]
y = df['Purchased']

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=0
)

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

model = LogisticRegression(random_state=0)
model.fit(X_train, y_train)

y_pred = model.predict(X_test)

cm = confusion_matrix(y_test, y_pred)
print("\nConfusion Matrix:")
print(cm)

TN = cm[0][0]
FP = cm[0][1]
FN = cm[1][0]
TP = cm[1][1]

print("\nTrue Positive:", TP)
print("False Positive:", FP)
print("True Negative:", TN)
print("False Negative:", FN)

accuracy = (TP + TN) / (TP + TN + FP + FN)
error_rate = (FP + FN) / (TP + TN + FP + FN)
precision = TP / (TP + FP)
recall = TP / (TP + FN)

print("\nAccuracy:", accuracy)
print("Error Rate:", error_rate)
print("Precision:", precision)
print("Recall:", recall)






# Logistic Regression – Theory

## What is Logistic Regression?

Logistic Regression is a supervised machine learning algorithm used for **classification problems**.

It predicts categories such as:

* Yes / No
* True / False
* Purchased / Not Purchased

In this practical:

* Output is `Purchased`
* `0` → Not Purchased
* `1` → Purchased

---

# Why is it called Regression?

Although the name contains “Regression”, it is mainly used for **classification**.

It predicts probability between:

* 0 and 1

Then classifies output.

Example:

* Probability > 0.5 → Purchased
* Probability < 0.5 → Not Purchased

---

# What is Classification?

Classification means predicting categories or classes.

Examples:

* Spam / Not Spam
* Pass / Fail
* Disease / No Disease

# Confusion Matrix

Confusion matrix evaluates classification model.

Structure:

\begin{bmatrix}TN & FP \ FN & TP\end{bmatrix}

---

# TP, TN, FP, FN

## True Positive (TP)

Model predicted YES and actual answer is YES.

Example:
Customer purchased and model predicted purchased.

---

## True Negative (TN)

Model predicted NO and actual answer is NO.

---

## False Positive (FP)

Model predicted YES but actual answer is NO.

Also called:

* Type I Error

---

## False Negative (FN)

Model predicted NO but actual answer is YES.

Also called:

* Type II Error

---

# Accuracy

Accuracy tells how many predictions are correct.

Formula:

Accuracy = \frac{TP + TN}{TP + TN + FP + FN}

---

# Error Rate

Shows wrong predictions.

Formula:

Error\ Rate = \frac{FP + FN}{TP + TN + FP + FN}

---

# Precision

Out of predicted YES values,
how many are actually YES.

Formula:

Precision = \frac{TP}{TP + FP}

---

# Recall

Out of actual YES values,
how many are correctly predicted.

Formula:

Recall = \frac{TP}{TP + FN}

---

# Advantages of Logistic Regression

1. Simple and easy to understand
2. Fast algorithm
3. Good for binary classification
4. Works well on small datasets
5. Gives probability output

---

# Disadvantages of Logistic Regression

1. Works mainly for linear data
2. Less accurate for complex datasets
3. Sensitive to outliers
4. Requires feature scaling
