# Theory – Data Wrangling and Data Preprocessing Practical

## What is Data Wrangling?

Data Wrangling means cleaning and transforming raw data into a proper format so it can be used for analysis or machine learning.

Real-world datasets usually contain:

* Missing values
* Incorrect data
* Different data types
* Categorical values
* Unscaled numerical values

So preprocessing is necessary before building any model.

# 5. Label Encoding

## Code

```python
le = LabelEncoder()

df['RainToday'] = le.fit_transform(df['RainToday'])
```

## Theory

Machine learning models cannot understand text values.

So categorical data must be converted into numbers.

Example:

| Before Encoding | After Encoding |
| --------------- | -------------- |
| Yes             | 1              |
| No              | 0              |

This process is called **Label Encoding**.

---

## What is `fit_transform()`?

It performs two tasks together:

### `fit()`

Learns unique values.

Example:

```python
Yes
No
```

### `transform()`

Converts them into numbers.

Example:

```python
Yes → 1
No → 0
```

---

# 6. Feature Scaling / Normalization

## Code

```python
scaler = MinMaxScaler()

df[numeric_columns] = scaler.fit_transform(df[numeric_columns])
```

# Why Scaling is Needed?

Different columns may have different ranges.

Example:

| Feature     | Values    |
| ----------- | --------- |
| Temperature | 10–40     |
| Pressure    | 1000–1030 |

Large values dominate smaller values.

Scaling brings all values into the same range.

---

# 7. Min-Max Normalization

## Formula

X_{scaled} = \frac{X - X_{min}}{X_{max} - X_{min}}

## Theory

Min-Max Scaling converts values between:

* 0 and 1

Example:

| Original | Scaled |
| -------- | ------ |
| 10       | 0.0    |
| 20       | 0.5    |
| 30       | 1.0    |
